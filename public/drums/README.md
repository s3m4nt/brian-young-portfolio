# Drum setup atlas

A standalone reference for backline techs setting up my kit (Ludwig Classic, Black Beauty snare, Paiste Giant Beat cymbals). It shows measured playing heights, center-to-center spacing, an orbitable 3D view and reference photos.

Vanilla HTML, CSS and JavaScript with no dependencies and no build step. It lives apart from the Next.js site on purpose and is served as-is at /drums (see the rewrite in next.config.mjs). The page isn't linked from the site and is shared by URL when needed.

- index.html: markup and styles
- app.js: kit measurements, canvas rendering and interactions
- photos/: reference photos of the final setup
